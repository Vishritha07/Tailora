# ✂️ Tailora

**Tailora** is a web-based tailoring platform that combines online shopping with clothing customization.

I built this project to create a simple platform where customers can browse ready-made clothes, place orders, or customize garments based on their preferences and measurements. It also includes an admin side to manage products and customer orders.

## 🌐 Live Demo

**[View Tailora Live](https://vishritha07.github.io/Tailora/)**

## 📌 About the Project

The main idea behind Tailora is to make the traditional tailoring process more convenient through a web application.

Customers can explore available products, choose between ready-made and customized options, provide their measurements, and place orders. The admin can add products and manage the orders received from customers.

This project also gave me an opportunity to understand how a frontend application can communicate with a real database using Firebase.

## ✨ Features

### 👗 Customer Side

* Browse available clothing products
* View individual product details
* Place orders for ready-made products
* Customize clothing based on available options
* Select fabric and design preferences
* Enter body measurements
* View placed orders and their status

### 👩‍💼 Admin Side

* Add new products
* Manage available products
* View customer orders
* Manage order information and status

### 🔥 Firebase Integration

* Firebase Firestore is used to store product and order information
* Product and order data can be updated dynamically
* The project demonstrates basic database integration in a web application

## 🛠️ Technologies Used

* **HTML5** – Structure of the web pages
* **CSS3** – Styling and responsive layouts
* **JavaScript** – Functionality and interactions
* **Firebase** – Backend services
* **Cloud Firestore** – Storing products and orders
